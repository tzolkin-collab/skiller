## 2026-10-06 - Added Database Indexes for Foreign Keys \n **Learning:** Drizzle ORM does not automatically add database indexes for foreign key constraints in Postgres, which can result in sequential scans and slow performance. This requires explicitly defining indexes using `index('idx_name').on(table.column)`.\n **Action:** Added indexes for foreign keys in `schema.ts` where necessary to prevent sequential scans when using foreign keys in where clauses.
