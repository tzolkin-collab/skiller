## 2026-10-23 - Missing Foreign Key Indexes with Drizzle\n**Learning:** Drizzle ORM does not automatically create database indexes for foreign key constraints in Postgres. This can lead to slow sequential scans on associated tables during lookups or cascade deletions.\n**Action:** Always explicitly define indexes for foreign key columns using `index('idx_name').on(table.column)` in Drizzle schema definitions.
