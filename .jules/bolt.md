## 2024-05-15 - [Fixing Payload Bloat with Explicit Selects in ORM]
**Learning:** By default, `.select().from(table)` in Drizzle ORM fetches all columns from the specified table. In this codebase, the `skills` table contains multiple large blob columns (e.g., `skillMdContent`, `humanMdContent`, `skillPackage`). Because `GET /api/skills` only needs to return summary data, fetching the entire table row creates massive node memory spikes and network payload overhead for lists.
**Action:** When working on list endpoints in this codebase that interact with tables holding large text or JSON payloads, always specify exactly which columns are needed in the `.select({ ... })` query rather than relying on default behavior. Additionally, complex json mappings (like `skillDocument->>'niche'`) should be queried on DB layer using `sql<string>\`\${skills.skillDocument}->>'niche'\`` instead of mapping entire blobs in JS.
