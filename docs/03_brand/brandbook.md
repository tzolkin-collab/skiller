## Essência da Marca

| Atributo | Definição |
|:---|:---|
| **Nome** | Skiller |
| **Tagline** | "Playlists → Knowledge" |
| **Posicionamento** | Ferramenta de engenharia de conhecimento que transforma playlists do YouTube em documentos estruturados de skill para agentes de IA |
| **Público** | Desenvolvedores, engenheiros de prompt, equipes técnicas que usam AI coding assistants |
| **Diferencial** | Gera skills no padrão SKILL.md (Antigravity/Claude) diretamente de playlists inteiras, não de vídeos individuais |

## Tom de Voz

| Contexto | Tom | Exemplo |
|:---|:---|:---|
| **UI / Dashboard** | Direto, técnico, conciso | "3 de 47 vídeos processados" (não "Estamos trabalhando nisso!") |
| **Erros** | Informativo, acionável | "Transcrição indisponível para este vídeo. Fallback ativado." |
| **Sucesso** | Factual, sem excesso | "Skill gerada. 42 conceitos extraídos de 47 vídeos." |
| **Docs** | Instructivo, sem jargão desnecessário | Foco em "como fazer", não em "por que somos incríveis" |

**Proibido**: emojis em UI funcional, linguagem de marketing ("revolucionário", "incrível"), mensagens genéricas ("Algo deu errado").
